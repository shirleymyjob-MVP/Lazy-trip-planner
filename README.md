# ✈️ 懶人行程規劃（原型）

睇 IG／YouTube／小紅書旅遊片，又懶得逐間搜尋、自己排行程？
MVP 只收**截圖**。真實用法係：見到地方就截圖，iPhone 撳「複製並刪除」，然後貼進行程匣，唔使先儲存去相簿再揀圖。

1. **行程匣（先做）**：Cmd/Ctrl+V，或者撳「從剪貼簿貼上」。每張可以寫短備註，例如「只要圖中 1、4」。未填日期同偏好都收得。貼完會自動認地方
2. **上傳已儲存圖片（次要）**：已經落咗相簿先用。備註一樣會交俾分析
3. **行程匣卡**：認到嘅地方、城市、備註、狀態（未排程／已排程），以及地址、營業時間、評分。基本核對唔使離開呢版
4. **開始排行程（稍後）**：先選目的地、日數、偏好、同行，再剔行程匣項目。AI 用營業時間、距離同呢啲選擇排日程
5. **下載**：行程 Markdown 會帶對得返嘅地址、營業時間、評分

唔會擷取 Instagram／YouTube／小紅書連結，亦唔會叫你貼店名或 Maps 連結做主要輸入。

## QA 手動步數

兩段分開計，因為收截圖同排行程可以唔同時間做。

**放入行程匣：1 步**（貼上之後）

- 桌面：Cmd/Ctrl+V，或者撳「從剪貼簿貼上」。自動認地方同入匣
- 備註可順手寫，唔使再撳確認
- iPhone：撳完「複製並刪除」之後，可能要先撳一下貼上框，再貼上（瀏覽器唔俾網頁背景讀剪貼簿）

**稍後排行程：1 步**

- 行程匣有地方之後，預設全選，撳「開始排行程」
- 目的地預設日本、3 日、美食同景點、同朋友。想改先選，唔使打字，亦唔使儲存。只有揀「其他」先有自由文字

地址、營業時間、評分喺行程匣卡同行程入面。

## 注意
- 呢個係原型：每個 browser session 有使用次數上限（重新整理會重置；正式版要登入先做到真正 per-user 限額）
- **成功**嘅入匣分析、開始排行程先計 1 次。失敗唔計。同一輪入面幾張圖、HTTP 重試、空回覆重試、分批請求唔另計
- 截圖只會用嚟即時分析，你手機其他資料唔會被接觸
- 多過 3 張截圖會分批同時送去 Gemini，單次請求有逾時。部分批次失敗會先列出其餘地方
- 備註提到圖中編號，但模型未有填到編號時，唔會清空成個清單，會保留結果並提示
- 「從剪貼簿貼上」要用瀏覽器 Clipboard API。Streamlit 元件框冇 `clipboard-read` 權限時，按鈕會改叫你喺貼上框按 Cmd/Ctrl+V 或長按貼上。貼上事件本身唔使呢個權限
- 地址、營業時間、評分：截圖有寫，或者模型有把握先填。未有就係對唔到，唔係叫你去 Maps 先睇到

## 部署設定（Streamlit Secrets）
| Key | 必填 | 預設 | 用途 |
|---|---|---|---|
| `GEMINI_API_KEY` | ✅ | – | Gemini API key |
| `GEMINI_MODEL` | | `gemini-3.8-flash` | 用邊個 Gemini 模型 |
| `MAX_ANALYSES_PER_SESSION` | | `10` | 每個 session 最多幾多次**成功** AI 動作 |
| `GEMINI_TIMEOUT_MS` | | `90000` | 單次 Gemini HTTP 逾時（毫秒） |
| `GEMINI_RETRY_ATTEMPTS` | | `2` | HTTP 嘗試次數（包含第一次；2 = 逾時／429／5xx 再試一次） |

## 本地開發
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pytest
mkdir -p .streamlit && echo 'GEMINI_API_KEY = "..."' > .streamlit/secrets.toml
streamlit run app.py
python -m pytest -q tests   # 用 mock，唔使真 API key
```

## 檔案
- `app.py` — Streamlit 入口。行程匣先，排行程後
- `components/inbox_paste/index.html` — 貼上框同「從剪貼簿貼上」
- `gemini_client.py` — Gemini 呼叫、prompt、JSON schema、逾時／重試／分批。備註會進分析，並按圖中編號再篩
- `trip_core.py` — 目的地清單、剪貼簿解碼、城市判斷、圖片縮細、JSON、去重、Google Maps 連結、行程 Markdown。貼店名／短連結解析仍然留喺呢度俾測試，唔係畫面入口
- `tests/` — 單元測試同 AppTest
